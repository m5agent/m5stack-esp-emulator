    Unit RGB

    SKU:U003

    Description

    Unit RGB is a smart LED strip unit that integrates three SK6812 programmable RGB LEDs. Through programming, users can independently control the color and 256-level fine brightness of each LED to achieve rich lighting effects. Its unique daisy-chain design allows multiple units to be easily expanded, forming longer light strips or complex lighting arrays. The unit is equipped with LEGO-compatible mounting holes, making it convenient to install in various structures or projects. It is an ideal component for STEM education, light art, ambient lighting, and interactive installation creation.

    Features

    • 3 × SK6812 programmable RGB LEDs
    • 256-level brightness adjustment
    • Supports daisy-chaining multiple Unit RGB units for expansion
    • 2 x LEGO-Compatible Mounting Holes
    • Development Platform
      • UiFlow1
      • UiFlow2
      • Arduino IDE

    Includes

    • 1 x Unit RGB
    • 1 x HY2.0-4P Grove Cable (20cm)
