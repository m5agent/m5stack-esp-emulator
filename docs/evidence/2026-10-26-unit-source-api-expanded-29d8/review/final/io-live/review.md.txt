## 运行身份、ZIP 与清理

九例 direct-PID receipt 一致绑定 runtime SHA `29d8f6ecdc83f4cbd2ca013291b05bc9ef44fb438a115b0ca97f7b5d46d8d28d`、`qemu-system-xtensa` 和 worker generation 11。分别核对 ready/running/before-evidence 原始 GET 与 ZIP 中同一个 PID、firmware SHA、worker identity 和 lease。

source CAS、每个 caller 文件 hash、`uiflow_source_sha256` 启动 pin、compose 返回 provenance 与 ZIP `firmware/uiflow-source.json` 逐一相等；无 binary-upload 请求。每个 ZIP 的所有成员 bytes/size/SHA、CRC、无重名成员、manifest 索引、source/attachment identity 和原 guest marker 均重新核对。原始 HTTP 记录证明 ZIP GET 先于 `DELETE ?purge=0`。其后 retained history 为 stopped、Flash=false、lease inactive、last frame=true，history PNG 确在 stop 后取得；保存的 cleanup health 均 active=0。当前 frame、history frame 与 ZIP frame 均为非单色原生 320×240 PNG。

这是历史执行文件复核，当前没有重复请求 health；PID executable hash 与 PID exit 的历史系统调用依赖已保存的 live sampler receipt 及冻结实现，无法在结束后重采样原进程。派生固件 BIN 不在本 review bundle 内，ADC 的派生镜像应用绑定依据 applied receipt 与 compose 的 outside-VFS unchanged/readback receipt；已独立重算的是实际 reference application bytes。通用 depth=2 QOM 根快照显示 truncated，不能称完整 controller dump；逐 Unit 数据来自原始 `/units` 的 guest-qom 数据和 observation，而非推定未保存的控制器状态。
