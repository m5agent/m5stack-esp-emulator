Subject: [PATCH] hw/m5stopwatch: gate SPI panel id on chip select

The direct SPI panel model returned its ST7789 ID for every W0..W15
read, regardless of the chip-select pin. M5GFX autodetection probes
several pin groups; an unasserted probe could therefore observe the
panel ID and select a different board (for example Cardputer became
DinMeter).

Return the panel ID only while the attached panel CS is asserted. This
keeps real CS-driven reads working while making non-selected probes
return zero.
