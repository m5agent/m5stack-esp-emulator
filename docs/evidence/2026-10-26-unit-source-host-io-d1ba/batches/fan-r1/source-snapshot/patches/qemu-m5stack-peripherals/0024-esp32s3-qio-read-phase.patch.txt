Subject: [PATCH] hw/ssi/esp32s3_spi: complete QIO read phase

ESP-IDF programs a one-byte dummy phase for 0xEB QIO reads. The m25p80
model requires five bytes after the 24-bit address (one mode byte and
four dummy bytes), so the first four data bytes were consumed as header
bytes and every read was shifted by four bytes.

Keep the guest controller timing unchanged while adding the missing
bytes only for QIO reads selected on flash CS0. This restores NVS,
LittleFS and instruction/data reads for Arduino ESP32 4.4.
