Subject: [PATCH] hw/block/m25p80: support GigaDevice status register 2

GigaDevice GD25Qxx exposes the quad-enable bit in status register 2 bit 1.
The ESP-IDF QIO boot path reads it with RDSR2 (0x35), writes it with WRSR2
(0x31), then verifies the bit. Without this model support, QIO setup fails
and firmware that asserts on esp_flash_init_default_chip() reboots at
startup_funcs.c:118.
