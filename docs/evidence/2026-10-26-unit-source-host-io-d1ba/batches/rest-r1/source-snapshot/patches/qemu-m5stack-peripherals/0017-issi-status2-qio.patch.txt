Subject: [PATCH] hw/block/m25p80: mirror ISSI quad enable into status register 2

ISSI IS25LP/WP parts use status register 1 bit 6 as the quad-enable control,
but the ESP32-C6 flash startup path verifies the resulting QE state through
RDSR2 (0x35) bit 1. Mirror the modeled quad-enable state into that register
so QIO setup succeeds for ISSI flash identities such as IS25LP128.

Apply after 0016-gigadevice-status2-qio.patch.
