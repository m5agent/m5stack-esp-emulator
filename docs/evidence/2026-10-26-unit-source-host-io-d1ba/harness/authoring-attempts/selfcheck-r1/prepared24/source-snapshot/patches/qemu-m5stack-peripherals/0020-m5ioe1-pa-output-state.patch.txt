Subject: [PATCH] m5ioe1: expose PA output state through QOM

StopWatch enables AW8737A through M5IOE1 G10, not M5PM1. Track writes to
the output-high register and expose the decoded G10 level so device-state
probes and unified-runtime evidence observe the actual amplifier path.
