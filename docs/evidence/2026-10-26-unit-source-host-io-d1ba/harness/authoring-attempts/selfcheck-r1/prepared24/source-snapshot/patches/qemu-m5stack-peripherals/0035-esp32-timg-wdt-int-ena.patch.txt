Subject: [PATCH] hw/timer/esp32: respect WDT INT_ENA for level interrupts

The ESP32 TIMG WDT raw status is not an interrupt request by itself. The
masked status is INT_RAW & INT_ENA. The ESP32 model currently raises the
WDT level line even when INT_ENA.WDT is clear, which injects a spurious
interrupt into guests that have deliberately masked the WDT source.

Only raise the level interrupt when the WDT enable bit is set. Keep the
raw status visible and leave the WDT stage timer behavior unchanged.
