Subject: [PATCH] esp32s3: map UART2 to an optional third serial chardev

StackChan keeps UART1 on the SCS servo bus and runs external HCI over
UART2. Without this mapping, QEMU accepted the third -serial argument but
left UART2 disconnected, so NimBLE commands reached no controller and the
host timed out with "HCI wait for ack returned 19".

Attach UART2 only when serial_hd(2) exists so existing machines that expose
one or two serials keep their current behavior.
