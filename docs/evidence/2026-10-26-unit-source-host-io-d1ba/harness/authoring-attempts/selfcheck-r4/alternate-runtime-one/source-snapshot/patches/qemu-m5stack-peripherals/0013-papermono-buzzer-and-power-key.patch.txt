Subject: [PATCH] m5papermono: attach buzzer I2S and power-key input

Wire GPIO42's M5Unified buzzer path to the ESP32-S3 I2S/GDMA model and
route the VNC P key to the board power-key signal.  This makes the
PaperMono buzzer observable through real TX PCM capture and allows both
PaperMono and PaperColor power-key paths to be exercised by QMP.
