Subject: [PATCH] m5stackchan: correct RTC and ambient-light routing

StackChan reuses the CoreS3 carrier, whose RTC is a BM8563 compatible with
PCF8563 at I2C address 0x51.  The board previously attached an RX8130 at
0x32, which is not present on StackChan and leaves the official RTC path
unconnected.  Expose absolute epoch and offset injection on both PCF8563 and
RX8130 models so automated tests can drive the real RTC register path.  Also
attach the CoreS3 carrier's LTR-553ALS-WA ambient-light/proximity sensor.

Signed-off-by: m5agent <m5agent@m5stack.com>
