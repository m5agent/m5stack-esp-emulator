Subject: [PATCH] m5-lcd-cam: expose runtime frame seed and auto-increment

Expose the deterministic GC0308/LCD_CAM test pattern through QOM and register
the camera model at /machine/m5-lcd-cam.  In auto-increment mode each completed
frame advances the seed, so a running guest can take multiple snapshots and
observe changing frame content instead of one boot-time image.

Signed-off-by: m5agent <m5agent@m5stack.com>
