# gen47 actual FlashLight route lifecycle evidence

Eight API lanes: PASS, 168 actual same-guest executions. CoreS3 mounted Web:
13 mandatory stages PASS, 14 owner executions. Hardware NOT RUN. Optional
browser body capture is PARTIAL: 7 empty HTTP200 frame observations; 676 HTTP304
observations correctly have no entity. Mandatory actual PNG/mounted evidence
does not use an empty optional capture.

Run `python3 -B verify.py` here. It uses the standard library and performs no
HTTP, browser, guest or Git actions. It explicitly requires all 8 API lanes,
their same-VM/cleanup evidence, all 13 mounted Web stages and failure separation;
an empty list of children cannot pass. Use `--check-originals --origin-root
<original-worktree>` only on the originating machine to check source bytes and
exact ASCII window membership in original ZIP UART bytes. Default portable
checks never follow token_file references or read a control token.

manifest.json distinguishes original, redacted-json, hash-only,
extracted-original-byte-window and generated records. Each payload redaction
records original/archive SHA and exact JSON pointers; it is never called
original. Raw ZIP/UART binary bytes, firmware/ROM/MPY and credentials are not
published. PNG bytes are allowed. The ASCII execution windows are exact
subsequences with byte offsets, not Latin1-to-UTF8 serial conversions.

Original narrow Torch r1/r2 FAIL reports stay unchanged. r1 had no accepted
functional frame; its independently matched ZIP/history failure frame proves
resource finalization only. The independent first verifier's strict-UTF8 error
is preserved; its later Latin1 check was in-memory only, no serial asset was
converted. The final raw-byte-window verifier uses original bytes directly.

The API case verifies internal unqualified phase and public settle/timeout
deadlines, then new supported EN fall and >500us recovery. It does not invent
reset-at-ns, controller waveform coverage or hardware facts. The Web owner
uses --web-only: selected_cases is a prepared inventory, not executed cases.
Source/program/frame/QOM/render samples are separate stable-stage samples,
not one atomic snapshot or exact browser texture-transfer proof.
