## Scope

- Modified `platform/web/unit-panel.js` and added `platform/tests/test_preview_unit_panel.mjs` only. Existing legacy `test_unit_panel.mjs` remains unchanged.
- Managed Unit reads and inputs consume the shared Preview client, captured immutable context and identity-checked `receipt.result`.
- Missing Run or malformed non-null management binding fails closed. Initialization only adopts frozen definitions, never unowned live Unit values.
- Context changes fence reads, receipts, queues, held sources, audio and values without detaching the assembly. Existing LED, drive and button visual feedback is withdrawn.
- A temporarily lost input ACK parks only a necessary release obligation. After fresh authoritative recovery of the exact same context, a bracketed Unit read confirms false without replay or permits one false correction for an observed true. New Run, terminal state, changed binding and disposal cannot retarget that release. An uncertain correction is not replayed in a loop.
- `dispose()` returns a cached `Promise.allSettled` for pending input queues. A confirmed hold with no pending queue dispatches its necessary same-Run keepalive release synchronously; an in-flight press preserves queue ordering, and ordinary queued inputs are dropped after disposal. The SessionVisual owner drains these promises before disposing the shared client.
