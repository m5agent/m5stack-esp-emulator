## 已观察事实与身份

[summary.json](summary.json) 记录每轮原始报告 SHA256/字节数、源码文件哈希、虚拟会话别名、
固件及 QEMU 哈希、帧哈希、像素、串口字节数、控制器两态与清场。未复制原始身份、端点、路径、nonce、源码内容或二进制。

- 实际红绿帧均为 `320×240`，`76,800` 非黑像素；模型屏幕颜色随同 guest 变化。
- Relay 虚拟控制器两态为 `false/true`；这是虚拟数据路径验证，不是触点或电气测量。
- 黑屏短任务有真实零非黑像素帧和串口标记；停止且 purge 后才恢复观察，仍可呈现终态。
- run-4 重启补充通过：短任务实际寿命 `3.905601 秒`，串口 `1,264` 字节在索引中保留；重启前后活动数为零，不复活 guest；已清理帧/串口保持 404。
- run-6 观察页 `401` 个请求全部 GET；自动焦点经过全景/组/特写，串口自动跟随底部。1920/1440 的宽高均适配一屏，390 无横向溢出；无可见交互控件或页面错误。真实 guest 清场后才启动逻辑夹具。
- 新建任务或 active→terminal 事件会使特写回全景；全景遇新活动至少保留 8 秒。忙碌时留在全景，稳定后恢复轮巡；Node 合同与真实短任务正控分别通过。
- 最终 14 个自有 guest 均已清场：12 条峰值末尾清场记录及单独的短任务/异常终止路径，无残留自有 guest 进程、无保留可变 Flash。
- 自动版短任务寿命 `3.624473 秒`，串口 `1,264` 字节、终态 stopped/purged；最终补充核对 15 个执行源码哈希，且后端三文件与已执行的重启验证相同。
- Python 全套第三轮 `2,035` 项（`2,034` 通过、`1` 跳过，`238.674 秒`）；自动 Node 合同 `33` 脚本通过。首次全套 `96 failure/21 error` 与第二次 `3 failure/2 error` 仍保留，分别为观测接入兼容/清场污染及接口/文档/fixture 收尾问题，不计作同数量固件故障。

## 复现与边界

在声明源码提交上运行 `node platform/tests/test_observatory_browser.mjs` 获取计划；显式执行
使用独立测试服务、私有凭据文件与新的忽略输出目录。宿主检查使用
`PYTHONPATH=platform/tools python3 -m unittest discover -s platform/tests -p 'test_*.py'`
及 `npm run --prefix platform/tests test:contracts`。实际参数/准入由源码脚本校验，记录不固化机器环境。

所有 guest 结果均为 **virtual-device validation**。64 逻辑模型不是 64 guest；详细模型预算
32 是配置，不能据此推断加载数量或吞吐。浏览器 WASM 执行、物理硬件、RF/功耗/电气/声学/光学、
长期稳定性和性能测量均 `NOT RUN`。run-6 记录的 15 个源码哈希均与验收时工作树一致，后端三文件哈希与重启补充版本相同。源码身份使用 base commit 加逐文件哈希，交付 commit 由外部工作记录绑定；后续通过不覆盖早期失败。
