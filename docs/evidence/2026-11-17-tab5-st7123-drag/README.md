# Tab5 ST7123 单点拖动

2026-11-17 · virtual-device validation。原生 Device Service 的普通
`/input` 向 ESP Part 提交一个完整拖动，来宾通过 GPIO23 和 HP I²C1
地址 `0x55` 读取同一个触点的坐标序列和释放。会话均未提供匹配 ELF。

- ESP-IDF 5.5.4 [来宾探针](../../../tests/firmware/tab5_st7123/README.md)
  正向读取 (0,1279)、(143,1023)、(287,767)、(431,511)、(575,255)、
  (719,0)，反向严格按相反顺序。两次均有六个数据帧、五次位置改变、
  一个释放和 7/7 控制器确认。来宾在释放后打印应用侧拖动完成标记。
  来宾计时分别为 362014 和 362013 微秒，控制器的虚拟拖动计时都为
  360 毫秒。空闲、点击及单点长按对照通过。
- 原版 Arduventure 的 A/B 与四方向点击未受影响。名字页右键长按
  1.2 秒仍从 A 移到 F，来宾读回 74 次刷新。该回归验证点击与长按。
- 同一个原版回归 worker 上，CarPlay 继续使用 GT911/ILI9881C。
  空白拖动 24/24 确认，单击仍打开已知配对清除确认框。

探针验证 ST7123 拖动。原版应用的拖动语义、多点、终态断电、浏览器、
USB/iPhone 和物理设备留待独立验证。所有会话均在保存证据后停止，
Flash 与租约已释放。Burner 未提交。
