# StickS3 已配网 Flash 的新会话

使用原版 v0.2.4 的应用和同工具链启动段冷启动。原版接收一次本地表单 POST 后在自己的 NVS 中写入设置，读取完整 Flash，停止最初的会话。之后把同一份已配网 Flash 作为 `merged` 重新上传，在另一个会话启动。

基线捕获两路客户端的 32 个 DHCP DISCOVER，未捕获 OFFER。旧对端一直等待门户的分配。候选只根据绑定来宾 STA 发出的合法 DHCP DISCOVER 切换，复用该帧完成 DORA，并收到 ACK 之后的来宾 ARP 应答。新会话没有门户 POST，应用字节未改，所有租约均已释放。初次配网仍通过。

[抓包摘要](summary.json)绑定原应用、复用 Flash、运行时与两份 pcap 的 SHA-256。本次只验证指定开放式隔离网络的站点连通性。
