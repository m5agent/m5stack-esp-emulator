# WebBurner part integrity

Last reviewed: `2026-10-25`.

This fixture checks optional integrity declarations on WebBurner `parts[]`:

- `size`;
- `sha256`;
- `sha1`;
- `md5`;
- the equivalent fields inside an `integrity` object.

The importer recomputes every declared value and rejects the package on a
missing file, invalid digest, negative size, size mismatch, digest mismatch or
conflicting duplicate declaration. A successful segmented manifest records
only `declared_integrity.status`, the checked algorithm names and whether a
weak digest (`sha1`/`md5`) was present. It does not copy the source package or
claim publisher authenticity.

Run:

```bash
python3 tests/firmware/webburner_part_integrity/run_test.py \
  --out /tmp/m5-webburner-part-integrity.json
```

The synthetic image is generated by the firmware-analysis test fixture and is
not committed. Digest checks prove accidental corruption detection, not a
digital signature, secure-boot execution, boot behavior or hardware state.
